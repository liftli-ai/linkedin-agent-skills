# Security

The skills in this repository are Markdown instructions that run on your own agent. They make no network calls,
need no API keys and store nothing.

If you find a skill that could lead an agent to do something unsafe (for example, leak private data, run an
unexpected command, or automate a website against its terms), please email support@liftli.ai instead of opening a
public issue. You will get a reply within a few days.

For the hosted Liftli service, see https://liftli.ai/terms.
