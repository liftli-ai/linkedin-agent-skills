# Changelog

New skills and fixes ship as tagged [releases](https://github.com/liftli-ai/linkedin-agent-skills/releases).

## v1.0.0 (2026-10-14)

- 31 single-purpose LinkedIn skills: posts, hooks, comments, profile audits and pre-publish checks.
- `linkedin-agent` routes any LinkedIn request; `linkedin-voice` builds the voice file every writing skill reads.
- Packaging for Claude Code (plugin), Cursor, Grok Build, Gemini CLI and the `npx skills` installer.
